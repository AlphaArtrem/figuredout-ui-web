Typography

Foundations/Type

The scale gains a display step above text-4xl — the package's largest type was PageHeader's 1.875rem, which is why every page read at the same volume. Two roles carry the system's voice: captions (mono, uppercase, 0.1em) name values, and figures (mono, tabular) are values.

Elevation & radius

Foundations/Elevation

Three shadow tokens, each with one job. Anything that covers something else uses --shadow-overlay — dialog, side panel, menu, toast, open tile — so "floating" always looks the same. Containment is an inset ring, never a border: rings do not change an element's size, so nested containers stay aligned.

Input, Textarea, Select

Primitives/Input

The one real change in the forms: a field now sits on surface-sunken rather than surface. A field is a hole you type into, and a white input on a white card was invisible without its border. Focus fills it back to surface and adds the standard 4px ring. The Select below is the real native control — its popup is drawn by the OS, and CSS can only ask (via color-scheme and option colours) rather than tell. Where the list must match the theme, that is what SelectMenu is for; every other dropdown on this page is one.

FormField

Primitives/FormField

Unchanged in structure — label, control, hint, error. The label stays sentence-case semibold rather than a mono caption: a form label is an instruction, and the mono caption role is reserved for labels that name a value. The error gains its icon so it is not colour-only.

Lowercase, no spaces. Used in the connection string.

Checkbox

Primitives/Checkbox

Drawn rather than a native box with an accent colour, so the checked state uses the same primary and the same focus ring as every other control — and so the indeterminate state actually renders. Same 1rem-ish hit area, same disabled treatment.

Switch

Primitives/Switch

Same size and travel. The off state gains a ring so it reads as a control on any of the four surfaces — previously it was a bare surface-sunken pill, which vanished inside a sunken container.

Skeleton

Primitives/Skeleton

A left-to-right sweep instead of an opacity pulse. A pulse reads as something asking for attention; a sweep reads as something still arriving — and on the new light ladder a pulsing sunken block flickered against the card behind it.

Spinner

Primitives/Spinner

A ring rather than a spinning arrow glyph: at 16px the arrow's tail is a smear, and a ring reads as progress at any size. Keeps role="status" and the visually-hidden label.

ThemeToggle

Primitives/ThemeToggle

Unchanged: a ghost button cycling system → light → dark, with the current mode's icon and label. It now has a second job worth noting — the light palette itself is a token set, so a product could expose the sage/paper/slate choice through the same control.

FilterBar

Patterns/FilterBar

A single ringed strip on surface, holding the controls that scope the view below it. Because fields are now sunken, the bar reads as a rail with holes in it rather than as a card with cards inside.

SearchInput

Patterns/SearchInput

SelectMenu

Patterns/SelectMenu

The listbox for options that need descriptions or disabled states, and the only dropdown whose list is themed — a native <select> popup belongs to the OS and stays light on a dark page. Every dropdown on this page except the native Select demo is this control, including the two in the gallery's own top bar. Its popover is the same surface as DropdownMenu and every other floating thing: raised, overlay shadow, strong ring, 4px padding so the highlighted row's radius nests inside the container's.

Dialog with a fixed footer: ghost cancel, then the confirm in primary or danger. Order is unchanged — the destructive action stays on the right, where the primary action always is, so muscle memory does not misfire.

SidePanel

Same right-edge sheet, same focus handling, two sizes. It now slides in 24px over --motion-normal rather than appearing, and its ring is on the leading edge only — the other three sides meet the viewport.

ToastProvider, useToast

Bottom-right stack, four tones, optional action, auto-dismiss at 4s.
